我建议将当前阶段正式定义为 **KRMM v0.2：知识重构可靠性诊断与证据约束修复（Evidence-Grounded Knowledge Reconstruction and Repair）**。

与 v0.1 不同，v0.2 不再优先追求更复杂的诊断模型，而是研究一个更加基础的问题：

> **当多模态模型的目标知识受损后，如何判断剩余知识能否可靠地重构目标事实，并在避免错误知识写入的前提下，实现持久修复？**

这一阶段应形成完整的技术框架、至少一种可复现的修复算法，以及能够区分残留知识访问、组合推理和错误猜测的实验体系。

## **一、总体技术路线**

KRMM v0.2 系统架构

**输入：受损多模态模型 + 待修复知识单元**

未知目标答案，不提供干净模型或损伤参数差值

残留知识提取

文本及关系先验

视觉证据提取

形状、结构、行为

声音证据提取

声学与事件属性

**模块 A：证据结构化与候选重构**

原子事实 → 关系约束 → 候选答案集合

**模块 B：可修复性诊断**

证据充分性 · 矛盾检测 · 关键证据干预 · 可靠性校准

**可尝试修复**

证据支持候选

**信息不足**

拒绝或请求更多证据

**模块 C：低干扰参数修复**

证据支持的伪标签 + LoRA + Retention KL + 回滚约束

**独立评测：候选正确性 · 持久恢复 · 邻近知识保留 · 跨模态泛化**

建议的研究顺序是 **P0 数据与损伤验证 → P1 候选可靠性 → P2 选择性修复 → P3 真实跨模态互补 → P4 泛化复验**。

其中 P0–P2 是当前阶段的核心任务。P3–P4 只有在前面通过后才推进。

## **二、P0：修复基准和损伤机制的科学有效性**

这是下一轮必须首先解决的问题。

根据现有 [实验代码](https://github.com/adsfasfbbc/KRMM/blob/main/krmm/experiment.py?utm_source=chatgpt.com)，我还发现一个需要优先消除的潜在捷径：

```
wrong = "ABCD"[("ABCD".index(gold(u)) + 1) % 4]
```

当前错误关联损伤使用固定的循环标签映射。如果模型稳定输出预设的错误标签，而某个方法知道损伤构造方式，那么只需反向移动一个标签就可能推断正确答案。

虽然 v0.1 的修复器没有直接使用这个逆映射，但它使任务存在**与剩余先验重构无关的潜在捷径**。

因此，新的实验应采用独立随机、类别平衡的错误目标，并控制损伤强度，保证不能由受损输出和公开损伤规则直接反推出真值。

此外，需要修正现有声源类别中的语义歧义。例如管乐器的激励体与共鸣体可能不同，不能简单将某个原子事实出现“簧片”判为知识错误。必须先明确目标究竟是乐器分类、初始激励机制，还是主要共鸣系统。

### **P0 的具体要求**

| 任务     | 技术措施                  | 验收目标              |
| ------ | --------------------- | ----------------- |
| 标签核验   | 独立核对实体类别、发声机制、激励体与共鸣体 | 消除已知标注歧义          |
| 损伤独立性  | 随机化错误目标，加入不同强度和不同机制   | 排除可逆标签映射捷径        |
| 原始掌握检查 | 使用独立问题和多种表达           | 达到预先固定的掌握率门槛      |
| 局部性验证  | 测试目标、邻近知识和通用能力        | 受损目标退化，保留能力满足门槛   |
| 监督写回上界 | 评测端提供正确答案，仅作控制        | 证明修复器在当前预算下具备写回能力 |

**旧封存测试不再用于新方法的确认性评价。** 可以使用旧数据分析缺陷和调试实现，但新结论必须使用新建、实体独立的测试集。

## **三、P1：候选重构与可靠性诊断**

这是 v0.2 最主要的方法研究。

### **模块 A：结构化知识重构**

保留现有的原子事实提取，但不再依赖简单关键词是否命中来决定候选。

新的过程是：

**步骤 1：抽取可检验的原子知识。**

把原模型的自然语言描述转化为如下结构：

```
{
  "entity": "instrument_X",
  "attribute": "excitation_mechanism",
  "value": "air_flow",
  "modality": "internal_text",
  "source_id": "probe_01",
  "conflict": false
}
```

同一个知识单元可以具有 `excitation_mechanism`、`resonator`、`material`、`observed_action` 等不同属性。

要保留原文和来源，不能只保存最后预测的标签。

**步骤 2：构建证据约束。**

定义通用的关系本体和推理规则，把原子事实连接到目标候选。规则只能描述普遍物理或分类关系，不能包含实体到目标答案的映射。

候选生成采用：

\\[ \mathcal Y_u(E)= \\{y:y\text{ 与当前证据及规则相容}\\} \\]

输出应当包含候选答案、支持路径、冲突路径和未解决的歧义。

如果所有规则都无法匹配，不应该像 v0.1 一样默认把生成式回退结果视为可靠候选。

**步骤 3：区分三种重构来源。**

| 重构类型               | 定义              | 科学用途     |
| ------------------ | --------------- | -------- |
| Direct residual    | 其他提问方式直接提取出目标事实 | 残留知识重新访问 |
| Compositional      | 多项保留事实组合后推出目标事实 | 核心研究对象   |
| Auxiliary evidence | 引入额外图像或声音后获得答案  | 辅助证据修复   |

这三类要分别统计。不能把所有成功统一称为“多模态知识重构”。

### **模块 B：证据充分性与矛盾检测**

我建议第一版实现一个 **Evidence Reliability Estimator（ERE）**。

它不需要复杂神经网络，先使用可解释的结构特征。

令 \\(E\\) 为允许证据，\\(c\\) 为候选答案，计算：

\\[ \phi(E,c)= [ s\_{\mathrm{support}}, s\_{\mathrm{ambiguity}}, s\_{\mathrm{conflict}}, s\_{\mathrm{key}}, s\_{\mathrm{sham}}, s\_{\mathrm{provenance}} ] \\]

六项分别表示：

| 特征              | 含义                 |
| --------------- | ------------------ |
| Support         | 是否存在完整、可追溯的支持路径    |
| Ambiguity       | 是否还有未排除的其他候选       |
| Conflict        | 证据之间是否存在真实语义冲突     |
| Key sensitivity | 删除决定性证据后候选支持是否合理下降 |
| Sham stability  | 添加或替换无关证据后候选是否稳定   |
| Provenance      | 证据是否来自重复或高度关联的来源   |

这里要特别注意：同一模型生成的两段回答不应被当作两个独立的知识来源。重复提示可以提高稳定性测量，却不能自动提高证据独立性。

对真实数据而言，ERE 是经过校准的**经验可靠性判断**，不能称为形式化正确性证明。

### **模块 C：可修复性决策**

第一版只预测：

\\[ p\_{\mathrm{candidate}} = P(\hat y_u=y_u\mid\phi(E,\hat y_u)) \\]

即候选事实正确的概率，而不是立即预测全部修复效果。

然后结合固定修复器，在独立校准集上估计：

\\[ P(\mathrm{repair\ success}\mid \hat y_u,\phi,\mathcal R,B) \\]

这一步允许输出三种决定：尝试修复、拒绝修复和证据不足。拒绝只代表当前方法与证据预算下不值得尝试，并非断言知识永久不可修复。

**必须比较的最强基线是 v0.1 的&#x20;**`candidate_change`**，不是仅比较模型置信度。** 现有 0.90 AUROC 的结果说明它已经非常强。

如果结构化特征不能提供额外收益，应保留简单规则，不需要强行增加参数量。

## **四、P2：至少一种有效的修复算法**

当前可以保留 v0.1 已经验证过的低秩约束写回，将创新实验集中在**修复前候选质量控制**上。

我建议将完整算法暂命名为：

**ECR — Evidence-Constrained Reconstruction and Repair**

具体流程：

1. 在不访问目标真值的情况下生成候选。
2. 用证据约束和反事实检查评估候选可靠性。
3. 对证据不足的目标拒绝更新。
4. 对通过诊断的候选执行固定预算的 LoRA 更新。
5. 使用受损模型在非目标保留集上的输出计算 KL 正则。
6. 写回后检查保留能力，违反预设阈值则回滚。
7. 在独立评测进程中撤掉辅助证据，测量持久恢复效果。

写回损失仍采用：

\\[ \mathcal L= \mathcal L\_{\mathrm{target}} + \lambda\mathcal L\_{\mathrm{retain}} + \mu\\|\Delta\theta\\|\_2^2 \\]

建议暂时冻结当前已验证的配置作为参考：Qwen2.5-Omni-3B、最后四层语言模块、rank 8、32 步修复、12 条保留提示。不要在改进候选生成的同时修改训练超参数。

**需要做两组隔离实验：**

| 实验     | 固定不变           | 改变因素                |
| ------ | -------------- | ------------------- |
| A：候选生成 | 诊断器、写回器、预算     | 原始生成 vs 结构化重构       |
| B：诊断选择 | 同一批候选、同一写回器、预算 | 候选变化 vs ERE vs 完整诊断 |

这样才能判断提升究竟来自更正确的候选，还是更好的可修复性判断。

此外，对所有合格受损样本，评测端仍须在隔离副本中执行固定修复，以便评估被拒绝样本是否本来可以修好。测试时的修复服务不得读取这些结果。

## **五、P3：真实视觉与声音的互补性实验**

这一阶段不能继续依赖当前只有四张图片、一条真实音频的媒体样本。

必须建立真实非语言声音和图像构成的配对数据，并确保原模型在无损状态下能够完成基础感知任务。

针对同一受损知识单元，采用以下对照：

| 条件             | 输入              |
| -------------- | --------------- |
| Internal       | 仅内部知识           |
| Vision         | 内部知识 + 图片       |
| Audio          | 内部知识 + 非语言声音    |
| Vision + Audio | 内部知识 + 图片 + 声音  |
| Matched text   | 内部知识 + 等信息量文字描述 |
| Shuffled       | 内部知识 + 无关或置换媒体  |

所有条件必须从**相同的受损模型参数**开始，采用一致的候选生成和写回预算。

特别设计一批互补任务：视觉单独不足以确定答案、音频单独也不足，但二者组合能够排除歧义。

如果双模态输入优于单模态，只能初步支持互补收益；还必须通过媒体置换和语义匹配对照，排除额外信息量、提示格式和数据捷径的解释。

**只有这里通过，才能将“跨模态知识互补”提升为论文的核心贡献。** 如果真实媒体始终不提供增量价值，就应收窄为“预训练模型残留知识的可靠重构与修复”，而不是继续扩大多模态主张。

## **六、实验门槛与评价指标**

建议新协议以“固定覆盖率下成功持久修复占全部合格受损单元的比例”为主要方法指标：

\\[ R\_{\mathrm{persistent}}= \frac{\\#\\{\text{成功且保留约束通过的修复}\\}} {\\#\\{\text{全部合格受损单元}\\}} \\]

同时报告候选正确率、错误写回率、AUROC、AUPRC、Brier 分数、计算成本和不同覆盖率下的风险曲线。

| Gate    | 核心问题              | 进入下一阶段的条件                      |
| ------- | ----------------- | ------------------------------ |
| **G0**  | 基准与损伤是否有效？        | 原模型掌握率、局部损伤、监督上界通过冻结门槛；无明显标签捷径 |
| **G1a** | 重构方法是否优于最强简单候选方法？ | 独立新样本上的候选增益获得配对统计支持            |
| **G1b** | 诊断是否有额外选择价值？      | 相同候选和预算下，优于候选变化基线，且配对差异区间下界大于零 |
| **G2**  | 真正的跨模态互补是否存在？     | 关键媒体干预与 sham 对照产生可重复差异         |
| **G3**  | 是否具备论文级稳健性？       | 第二模型、多损伤种子、独立数据与完整复验           |

这张表是提议门槛，不应在看见新测试结果后修改。

样本规模建议从开发集小样本开始，正式测试数量依据开发阶段估计的配对差异和统计功效确定。原来 16 个封存合格样本不足以可靠判断一个可能只有几个百分点的增量效果。

## **八、当前阶段的科研边界**

当前状态：PLAN / PIVOT

现有 20 次授权实验已全部完成，云端环境已执行关机。本技术路线没有启动新的实验，也没有更改仓库。

### **我建议这一阶段优先验证的唯一核心假设**

**对受损知识进行结构化、可干预的证据检查，能否比“候选是否改变直接答案”更可靠地识别正确候选，并减少错误参数写回？**

如果答案是肯定的，就获得了一个有科学解释的修复框架；如果答案是否定的，就应当接受简单诊断已足够有效的结果，把研究重心转向更困难的组合知识重构，而不是继续增加诊断模型的复杂度。
