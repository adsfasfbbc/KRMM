# V8-A 格式与非零合并诊断

只使用重建 M0 和同一组已验证 LoRA 产物。冻结后运行一次主进程和一次独立 GPU 重载，不重新训练。原始 v0.7 目录与已完成的 v0.8 重建运行均只读。独立重载在主进程退出后启动，避免两份模型同时驻留。

六条历史已知事实包括三条重建 D3 最终错误和三条稳定对照。保留原固定问法 F0。在 F1 中保持选项文本不变并轮换四个位置，按原语义选项编号评分。在 F2 中使用无选项开放问法，贪心生成最多 32 token，固定别名比较前进行 Unicode 归一、小写、去边缘标点和去前置冠词，未对应到正确或明确错误别名的项记 unclassified。F3 使用新写的独立释义及重写选项，四位置均衡。依据重建结果选取诊断样本，结果只说明本次 REPLAY。因开放题无重复标注者，人工一致率不可用。报告严格语义支持、纯固定格式错误和证据不一致，保留 unclassified。

格式主比较为 M0、三条既有单目标写回合并权重、D3 最终合并权重。非零三路审计对 cedar、slate、meerkat 三条 D2 写回分别比较同一 adapter 的未合并 forward、BF16 合并 forward 和全新模型进程中的 M0 + adapter 合并。并列记录理论 FP32 有效 ΔW、PEFT dtype 的有效 ΔW、实测合并增量、舍入误差、权重哈希、选项概率偏差与语义标签翻转。重载通过要求合并状态哈希相同、所有选择题探针标签相同、最大条件概率差不高于 1e-4，并报告开放文本差异。未合并与合并间的数值差异作为诊断结果保留。

V8-A 本次最多 30 分钟主进程 + 20 分钟子进程，1 次主启动、1 次独立重载、0 次拟合。重建已记 0.2392 GPU 小时，V8-A 子额度为 2 小时。新增最多 1 GiB，保留至少 15 GiB。进程退出码、超时、拒绝或失败保存在新的 append-only 运行目录。本批不含自动重试或 V8-B。
