# H1: incremental fact-level repairability prediction

Hypothesis: pre-update support structure and gradient conflict improve prediction of fixed-budget persistent repair over confidence AND the strongest single pre-update feature on entity-held-out targets.

Falsifier: the paired improvement interval includes zero; a simpler candidate-change/support predictor matches performance; gains require more model calls; calibration or test sample counts fail the prespecified minimum. Candidate quality gain alone does not validate selector gain. Frozen final test cannot be used for tuning.

Other hypotheses: H2 key-versus-sham evidence intervention (controlled support only); H3 correct candidates can differ in writable risk (may be underidentified if every correct candidate writes successfully); H4 equal-coverage selection increases successful repairs over ALL eligible units at matched writer budget. G0 failure blocks confirmatory promotion; all current real analyses are exploratory conditional characterization.
