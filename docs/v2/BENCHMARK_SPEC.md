# New benchmark ownership and semantics
Target is explicitly four acoustic Hornbostel-Sachs families: A chordophone, B aerophone, C membranophone, D idiophone.
Exciter, resonator, material and performance action are distinct attributes. Reed excitation does not imply idiophone; a membrane soundboard on a bowed lute does not imply membranophone. Hybrid/electronic/ambiguous labels are excluded with recorded reasons.
Museum catalog category and HS first digit must agree; retain exact API item URL, minimal label record and source SHA256. Raw catalog stays in private cloud setup directory; descriptions never supplied to repair.
Source: Grinnell College Musical Instrument Collection, curator Roger Vetter; MIMO 2011 revision. Museum names may require expert alias adjudication; freeze new entity groups prospectively.
Old 60 entities, obvious synonyms and variants are excluded. Multiple exemplars, spellings and same named instrument variants form ONE entity group. Splits by normalized entity group, never object row. Dev and calibration never test.
Repair receives public UID/name/task, damaged model and its own probes ONLY. It never receives labels, HS codes, source catalog attributes, damage wrong target, clean model/delta, eligibility evaluations or counterfactual repair results.
Model knowledge of taxonomy is allowed; lookup entity-to-family tables are forbidden in reconstruction rules.
All source attribution is empirical; model probe spans preserve raw generation and share provenance group damaged-model. Repetition does not create independent sources.
True composition requires >=2 jointly decisive facts with every individual fact ambiguous. A single sounding-element fact is residual/one-hop, never genuine composition.
