# KRMM project brief

Question: predict unit-level success of a fixed answer-free persistent repairer from allowed pre-update evidence, under a fixed low-rank update budget and retained behavior constraints. Test initially mastered, independently damaged units; report every exclusion and the all-eligible denominator.

One authorized RTX 3090; maximum 8h wall time, 20 child experiment launches and 80GB additional storage. Code/runtime only on the supplied cloud server and the named GitHub repository. Shut down after evidence is synchronized.

Primary comparison: fixed candidates/writer, equal acceptance coverage, full predictor versus confidence, consistency, random, strongest single feature and candidate-change baseline. Conditional pilot only; no target truth or original clean weights are consumed by repair modules. Original calibration coverage failures remain reported. No paper-ready or novelty claim.
